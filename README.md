# Simple TODO app

It listen to a user input, and save tasks into file tasks.txt.
On loading it try to load tasks from tasks.txt

User interface:
1. Add task
2. Complete task
3. Edit task
4. Delete task
0. Exit

## Before run - create and activate a virtual env

```python3 -m venv .venv
source .venv/bin/activate```

## Run app

```python3 app.py```

## Run tests

```python3 -m pytest```
